== Features

pf-adm is an open source project which integrates http://primefaces.org/[Primefaces 15], https://getbootstrap.com/[Bootstrap 5] and https://adminlte.io/[AdminLTE 4].

The project is inspired and partly based on https://adminfaces.github.io/site/[AdminFaces] by https://github.com/rmpestano[Rafael Pestano] which is based on Bootstrap 3 and AdminLTE 2.
